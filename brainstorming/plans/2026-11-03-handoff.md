## 一、项目：校园闲转（微信小程序）

**路径**：`F:\Data\Documents\AI\xiaoyuanershou`
**性质**：课程设计，2026-11-06 汇报，后续可能上线
**云环境**：`cloud1-d3g6gs20f620ed7b5`（微信云开发，免费版）
**技术栈**：原生小程序 + 微信云开发（云函数 / 云数据库 / 云存储）

### 1.1 当前架构

```
pages/*  ──►  services/*.js  ──►  utils/api.js  ──►  云函数 api（33 个 action）
                                                        └─ 云数据库
```

| 目录 | 作用 |
|---|---|
| `cloudfunctions/api/` | 路由 `index.js` + `lib.js` 鉴权/查询 + `actions/{auth,goods,chat,favorite,order,admin}.js` |
| `services/` | user / goods / chat / favorite / order / admin 六个薄封装 |
| `utils/` | api（唯一调用入口）、guard（登录/封禁/错误）、watch（双 openid 订阅）、format、avatar、view、config |
| `pages/` | 15 个页面，含新增的 `account`（账号管理） |

### 1.2 身份模型

- 以 **openid** 为准，学号通过 `whitelist` 校验并绑定
- `admins` 集合 + 服务端常量 `ADMIN_SID=000000000` 双重判定管理员
- 四个开发账号：000000001 / 000000002（小帅，即当前用户）/ 000000000（管理员，在另一位同学手上）/ 000000003

### 1.3 云开发配置（已完成）

| 集合 | 权限 |
|---|---|
| `messages`、`reads` | 自定义规则 `doc.openidA == auth.openid \|\| doc.openidB == auth.openid`，write false |
| 其余 9 个集合 | 所有用户不可读写 |

**云存储权限是「仅创建者可读写」，且升级到「所有用户可读」需付费版** —— 这是本轮所有图片方案的根因。

### 1.4 本轮完成的关键改动

1. **安全重构**：写操作全部迁到云函数，客户端只保留展示；删除客户端 `ADMIN_SID`
2. **登录**：白名单 + openid 绑定 + `autoLogin` 免密登录；邮箱不限域名（兼容 QQ 邮箱、全角符号、空格）
3. **封禁**：服务端校验发送者本人（原来只校验对方）；联动下架商品、禁发布、禁聊天
4. **消息**：openid 维度会话（`chats` 集合）；`localId` 回写解决消息闪两条；双 watch + 3 秒轮询兜底
5. **商品**：`sold` 状态；下单即锁定；卖家详情页可改价/上下架/删除；列表分页 20 条
6. **图片**：因云存储私有，改为 **云函数下载 → base64 存库**；列表用缩略图（≤28KB）、详情用大图（≤180KB）
7. **头像**：emoji（25 个，4×5 网格）或 base64（96px）双模式
8. **账号管理页**：改昵称/邮箱/头像、退出登录、注销（软删除）
9. **性能**：`violations` 30 秒缓存、首页下拉刷新、图片 lazy-load
10. **自检脚本**：`scripts/check-bindings.js`、`check-refs.js`、`smoke.js`
